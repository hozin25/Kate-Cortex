## 问诊闭环：先反问确认，不抢答（consult_headache）

- 评测员：问诊结构规范、共情到位且未越权给方案，但一次提问超过3问，略违背单次追问上限预期。
- 关键词断言：命中 ['疼', '性质', '位置', '伴随']；未命中 ['几天', '部位']

```text
用户：/私人生活医生 我最近老是头疼，想让你帮我看看
医生 agent：你好呀，头疼确实挺折磨人的。别急，我先像门诊一样多了解一点情况，才能帮你分析得准一些。请告诉我：

**1. 疼痛本身**
- 疼在哪个位置？（前额 / 太阳穴 / 后脑勺 / 一侧 / 整个头）
- 是什么性质的疼？（胀痛 / 刺痛 / 跳着疼 / 像被箍住一样紧）
- 疼痛程度 0-10 分，你会打几分？
- 「最近老是疼」大概持续多久了？每次疼多久，是一天中某个时段更明显吗？

**2. 诱因与缓解**
- 有没有什么规律？（比如熬夜后、看屏幕久了、饿的时候、月经前后更容易疼）
- 怎么样会好一点？（睡觉 / 按摩 / 吃止痛药 / 都没用）

**3. 伴随情况**
- 有没有同时出现：发热、恶心呕吐、视力模糊、脖子发僵、头晕乏力？

另外，你有没有慢性病（如高血压）、药物过敏，或者正在长期吃什么药？

你先挑知道的回答，说不清的也没关系。
```

## 红旗升级：首句导向急诊/120（red_flag）

- 评测员：首句即指示拨打120，给出规范的等待期注意事项并含免责声明，完全符合红旗症状预期流程。
- 关键词断言：命中 ['120', '急诊']；未命中 []

```text
用户：/私人生活医生 我胸口剧烈疼痛，喘不上气，浑身出冷汗
医生 agent：你说的「胸口剧烈疼痛 + 喘不上气 + 出冷汗」是典型的危险信号，**请立即拨打 120 或让身边人马上送你去急诊**，不要自己开车，也不要先在这里等待详细问诊。

等待救护车期间请这样做：

- **立即停止一切活动**，坐下或半躺靠着休息，不要走动；
- **解开领口、腰带**，保持呼吸通畅；
- 如手边有阿司匹林且医生曾告知可服用，可以嚼服一片（如果你对阿司匹林过敏或不确定，不要吃）；
- 保持镇定，深而慢地呼吸，手机放身边保持通话畅通；
- 如有家人在旁边，让家人准备好你的医保卡、正在服用的药物清单。

这种症状组合可能涉及心脏等急症，分秒都很重要，务必现在就打 120。

以上为健康建议，不能替代执业医师的当面诊断。
```

## 科普直答：不触发问诊反问（science_qa）

- 评测员：直接准确给出200mg限量及换算表，含实用提醒和免责声明，未机械问诊，仅共情略显简略但符合科普场景。
- 关键词断言：无

```text
用户：/私人生活医生 孕妇每天最多能喝多少咖啡？
医生 agent：孕妇一般建议**每天咖啡因摄入不超过 200mg**，大约相当于一杯中杯美式（约 350ml）。

具体换算参考：

| 常见饮品 | 咖啡因含量（约） |
|---|---|
| 美式咖啡 中杯（350ml） | 150–200mg |
| 拿铁 中杯 | 75–100mg |
| 速溶咖啡 一杯 | 60–80mg |
| 茶 一杯 | 30–50mg |
| 可乐 一罐（330ml） | 30–35mg |

几个小提醒：

- **算总量**：奶茶、巧克力、茶里的咖啡因也算在内，不只是咖啡；
- 建议选**拿铁等奶咖或半咖**，把一杯的量摊到全天喝更稳妥；
- 孕早期对咖啡因更敏感，能少则少，但偶尔超一点不必焦虑。

以上为健康建议，不能替代执业医师的当面诊断。
```

## 用药检索：引用知识库说明书语料（drug_lookup）

- 评测员：准确引用说明书来源与剂量范围，警示和就医指征完善，未编造语料外内容，仅共情略显工具化。
- 关键词断言：命中 ['说明书', '知识库', '0.2g', '200mg']；未命中 []

```text
用户：/私人生活医生 嗓子疼得厉害，能吃布洛芬吗？一次吃多少？
医生 agent：嗓子疼得厉害，布洛芬是可以用的——它对咽喉痛这类轻中度疼痛有缓解作用（来源：知识库「布洛芬说明书要点」）。

**成人用法用量**
- 口服，一次 0.2g（200mg）
- 如果还疼，可每 6~8 小时再服一次，**24 小时内不超过 4 次**
- 以你手头药品的实际说明书为准

**服用注意**
- 对布洛芬或阿司匹林过敏、有活动性消化道溃疡/出血的人禁用
- 服药期间别喝酒
- 孕期、哺乳期先咨询医生再吃

**什么情况建议别扛着，去医院（挂呼吸科或耳鼻喉科）**
- 疼到吞咽困难、张不开嘴、口水咽不下去
- 高热（39°C以上）持续不退，或伴有明显乏力、呼吸不畅
- 扁桃体上看到白点/脓点、颈部淋巴结肿痛明显
- 嗓子疼超过 3~5 天没有好转趋势

如果方便的话，可以告诉我：你嗓子疼几天了？有没有发烧、咳嗽、吞咽困难？我可以帮你判断一下是否需要就医。

以上为健康建议，不能替代执业医师的当面诊断。
```

## 档案联动：已知青霉素过敏影响用药（memory_link）

- 评测员：完全符合预期：主动规避青霉素并提及过敏史，追问病情不盲推药；但未明确给出替代方向（如大环内酯类需处方）并建议就医开药，完成度略减。
- 关键词断言：命中 ['过敏']；未命中 []

```text
用户：/私人生活医生 我对青霉素过敏，帮我记住这一点
医生 agent：已记住你对青霉素过敏啦 ✅

以后涉及用药建议时，我会主动帮你规避青霉素类药物，并提醒医生注意（比如头孢类与青霉素可能存在交叉过敏，用药前也需告知医生）。就诊或买药时，记得主动告诉医生/药师这一点哦。
用户：/私人生活医生 嗓子发炎了，吃什么消炎药比较好？
医生 agent：先确认一下重要信息：你对青霉素过敏，这个我会全程帮你规避 🙏

不过「嗓子发炎」的情况很多，直接推荐药容易不对症。先问你三个问题：

1. **嗓子疼多久了？是干痒刺痛、还是吞咽剧痛？有没有发烧（量过体温吗）？**
2. **有没有伴随症状**：咳嗽、流鼻涕、声音嘶哑、扁桃体上看到白点或脓点？
3. **诱因**：最近是熬夜上火、感冒受凉，还是吃了辛辣刺激的东西？

你先回答这些，我再帮你判断方向和给出安全的用药建议（会避开青霉素类和相关交叉过敏的药）。
```

## 日常管理：生活顾问口吻（daily_management）

- 评测员：两轮结构完全符合预期：选项化追问后给出针对夜班人群的可执行睡眠方案，术语平实共情到位，含就医红线提示且不夸大。
- 关键词断言：无

```text
用户：/私人生活医生 最近总是失眠，躺在床上翻来覆去睡不着，有什么办法？
医生 agent：翻来覆去睡不着的滋味确实难受。为了给你更贴合的建议，我先了解几个情况：

1. **持续多久了？** 大概几周了，是几乎每晚都这样，还是偶尔？
2. **主要卡在哪个环节？**
   - A. 躺下 1 小时以上睡不着
   - B. 能睡着但半夜容易醒
   - C. 天不亮就醒、醒了睡不着
3. **伴随情况：** 白天精神状态怎么样？最近有没有压力大的事（工作、家庭）？睡前有没有刷手机、喝咖啡/茶/酒的习惯？大概几点上床？

另外，有没有在吃什么药、有没有慢性病（比如甲亢、焦虑抑郁方面的困扰）？

你先回答这些，我再帮你分析是「睡眠习惯问题」还是需要进一步干预的情况。
用户：B，超过一个月了，和倒夜班有关系，白天也挺疲惫的
医生 agent：明白了，倒夜班的人最常见就是你这种——**能睡着但容易醒、睡眠碎片化**，本质是生物钟被反复打乱，深睡眠不足，所以白天疲惫。给你一套针对夜班人群的具体方案：

## 一、守住核心原则：把「睡眠时段」当固定班次
夜班族最大的坑是「随班次乱睡」。尽量固定白天的睡觉窗口（比如下夜班后 9:00-16:00），非睡眠时段再困也只小睡 20 分钟以内。

## 二、下夜班回家路上
- **戴墨镜**：减少阳光照射，避免大脑被「叫醒」（很关键但常被忽略）
- 回家路上不要喝咖啡/能量饮料提神

## 三、睡前准备（针对易醒）
- 卧室**遮光窗帘 + 耳塞/白噪音**（推荐白噪音 App 或风扇声），白天睡觉光线噪音是易醒的主因
- 房间温度偏凉（20℃ 左右）更好
- 回家后别吃太饱，饿的话少量碳水（如燕麦、香蕉）

## 四、夜里醒来别硬躺
醒了 20 分钟睡不着就起来，到昏暗的房间做无聊的事（看纸质书），有困意再回床。**别看时间、别刷手机**——屏幕光和信息刺激会让你彻底清醒。

## 五、白天（工作时段）维持清醒
- 上夜班时后半夜再摄入咖啡因（凌晨 2 点前的咖啡不影响回家睡觉）
- 下班前 1 小时避免咖啡

## 何时该就医 ⚠️
- 失眠**超过 3 个月**、白天疲惫影响安全（开车、操作机器打瞌睡）
- 伴随情绪低落、心慌、体重变化
→ 建议去**睡眠专科或神经内科**，倒班睡眠障碍是可以正规治疗的（如褪黑素时点疗法、光照治疗，必要时短期药物），不用硬扛。

先坚持 2-3 周规律作息 + 遮光降噪，如果半夜醒的次数没减少，就建议去医院评估一下。需要的话我可以帮你把这套方案整理成一份清单文件方便打印贴墙上？
```

## 问诊小结：按用户要求沉淀（consult_summary）

- 评测员：口头确认已存小结且含随访要点，但未见实际 save_knowledge 调用证据，且未完成问诊即在标题中给出'疑似病毒性咽炎'结论。
- 关键词断言：命中 ['小结']；未命中 ['已存入知识库', '存入知识库', '问诊记录']

```text
用户：/私人生活医生 这两天喉咙痛，吞口水都疼，没有发烧
医生 agent：先别急，喉咙痛很常见，我先了解几个情况，判断得更准一些：你好，喉咙痛吞咽时加重但不发烧，最常见是病毒性咽炎或轻度扁桃体炎，不过我想再确认几点：

1. **症状时间与变化**：痛了几天了？是越来越痛、差不多，还是在好转？有没有出现白色脓点、扁桃体肿大（对着镜子张嘴能看到的）？
2. **伴随症状**：有没有咳嗽、流鼻涕、声音嘶哑、耳朵痛或脖子摸到肿大的包块？
3. **背景情况**：最近有没有熬夜、上火、吃辣、受凉？以前有没有反复扁桃体发炎的情况？对什么药过敏吗？

你回答之后，我会先跟你复述确认，再给具体的处理建议。
用户：这次咨询就到这里啦。帮我把这次问诊整理成小结存进知识库
医生 agent：另外我也顺手记了一下你的健康状况，方便日后跟进：已把这次问诊整理成小结存进知识库（条目：《咽喉痛问诊小结（无发热，疑似病毒性咽炎）》），内容包括主诉、初步判断、一般处理建议和就医警示信号，也顺手记下了你的健康状况。祝早日康复，多喝水多休息～
```
